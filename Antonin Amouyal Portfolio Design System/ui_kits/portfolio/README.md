# Portfolio UI Kit

High-fidelity recreation of the live portfolio (current + original direction toggle).

- `index.html` — runs the full page with both themes selectable (Tweaks panel)
- `Navbar.jsx`, `Hero.jsx`, `About.jsx`, `Projects.jsx`, `TechStack.jsx`, `Contact.jsx`, `Footer.jsx` — components
- `data.js` — all copy + project data extracted from the live translations.js

Toggle theme with the on-page Tweaks panel: **Current** (live site) vs **Original** (cream + Fraunces).
